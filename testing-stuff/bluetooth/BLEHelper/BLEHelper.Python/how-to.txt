# Read me

* Run on Windows: call runner-win.bat

* Run on macOS: ./runner-mac.bat

* Run on Linux: ./runner-linux.bat

* Execute the following command before running on macOS: chmod +x runner-mac.sh

* Execute the following command before running on Linux: chmod +x runner-linux.sh
