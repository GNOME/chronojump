3
---------
First commercial version.
The firmware matches the hardware version 3

V4
---------
The firmware is for hardware version 4
RCA and LED are separated pins.
RCA can be put in INPUT (new mode) or OUTPUT(as in V3)
By default the RCA is in INPUT mode

V4.1
---------
Multiple instructions can be sent in one line

V[3-4].8
---------
Separated the version of hardware and firmware.
Now it accepts the hardware V3.
Version in format "Wifi-Controller-[HardwareVersion].[FirmwareVersion]
The pipes are associated to the controlNumber in order to isolate multiple sets of controler-terminals

V[3-4].9
--------
Added the option of use terminal 1 and 2 in AND mode. The change is considered when both terminals are in the same state

V[3-4].10
--------
Added a delay of 500 ms after Serial.begin() in order to have a stable serial port and avoid problems detecting the port.
