---------- ---------- ---------- done until Nov 3 included ---------- ---------- ---------- Version 2.6.0 2026-Jan-12 (Differences from 2.5.2-63 2025-Sept-2) New features for all modes:
  • Boxplots on session results:
    • All the resultsSession graphs have boxplots.
    • Boxplots show quartiles, median, mean and outliers.
    • Unseen data (eg. show with a filter 7 jumps when there are 10 on session, it will show the other 3 as diamonds. This is very useful for encoder as saved repetitions of one set can be shown or not on the graph. The diamonds help to understand that.
    • Seen data is shown with a gray rectangle. And the limit spinbutton it is also on grey to help understand this behaviour.
    • This characteristics help to don't feel lost when a jump so low is done but it is not shown on graph because is sorted by height and limited to n jumps.
    • Removed old max/min arrows.
  • All selected data on tables/graphs is shown in yellow. Even yellow rhombus on resultsSession graphs.
  • Persons management:
    • Person has now name and surname: shown on all parts of the program. It can be sorted by name or surname on left of the screen. Fixed all the add/load/import persons methods.
    • Persons can be exported to a csv file (including just persons from session or all persons).
    • To fix migrations between persons in different devices, now persons now have also a muuid with machineID and person UUID. Database name can be edited (preferences/advanced).
  • External window:
    • External window at capture for jumps and races. It shows the progress and the final result.
    • Useful for showing in another screen for the runner or the audience.
  • Selected row in any data treeview is in yellow. It helps to identify better the test we are evaluating, editing, ...
  • At session results graph now we can right click to edit/delete/repair. This behaviour is distinctive with a mouse icon with two colorized buttons.
  • Added Bluetooth tests on preferences/advanced.
  • On editing a test date is shown and can be selectable.
  • After importing jumps, runs .csv, the persons treeview n is updated now.
  • Fixed a crash on migration of DB 2.64->2.65 when there are no persons. This affected to few people who have Chronojump installed, they have no persons in the db (no data at all) and they updated to 2.5.2
  • DB version: 2.75 (DB of 2.5.2-63 was 2.66)
  • Fixed bad behaviour on Windows 11 after capture full screen where some icons got misaligned and user cannot click. Now that fullscreen is always decorated (with windows controls) and then on restore windows misalign does not happen.
  • getNews disabled until fixed problems on Linux with faulty Eduroam.
  • Fixed "Kg" to "kg" on many parts of the program.
Encoder:
  • Encoder if cannot capture (usually drivers windows) prevents crash and show message.
  • Fixes on edit a encoder test (Thanks to Kishore for all the debugging):
    • Encoder edit a test does not update max force, max power on DB (and on resultsSession treeview).
    • If encoder set weight is decimal it gets incorrectly shown on edit_event.
  • Fixes problems with triggers since last versions.
Force Sensor:
  • Improvements on analyze model:
    • maximumIsometricForce.R manages better sdMethod problems.
    • Improvements on analyze: optimized model by sd: Fixes on model, shows error if any, store on DB, better gui.
    • RFD SD start sample method now finds the most stable second.
  • Force sensor resultsSession graph shows only 1 bar (max/bestSecond).
  • In force sensor analysis, show differences of two sets. Before it was showing only AB and CD data, now it shows also the diff and the diff%.
Race Analyzer:
  • RaceAnalyzer resultsSession graph shows only 1 bar (speed/bestSecond).
  • On Sprint export, shown "This will export only Sprint data."
Jumps:
  • Shown time after capture at top right
  • Jump height use always 1.22625
WICHRO:
  • Run with tracks can show speed/time on current set graph
  • Run with/without tracks can show speed/time on resultsSession graphs
  • Shown time after capture at top right
